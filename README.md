# GunTanks Multiplayer

The new projects are separated at the repository root:

- `guntanks-client`: browser client and copied game assets.
- `guntanks-server`: authoritative Go HTTP/WebSocket server.

Run the server from `guntanks-server` with `go run .`, then visit `http://127.0.0.1:8889`. Detailed configuration and verification commands are in `guntanks-server/README.md`.
